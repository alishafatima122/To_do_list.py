# To-Do List
A beginner-friendly Python to-do list application that helps users manage their daily tasks through a simple command-line interface.

## Features

- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using a file

## How It Works

1. The user selects an option from the menu.
2. Tasks can be added, viewed, completed, or removed.
3. The program saves task information so it can be accessed later.

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Run the file:

python todo_list.py
